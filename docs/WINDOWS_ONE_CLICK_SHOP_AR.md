# تشغيل نظام المحل بضغطة واحدة على ويندوز

> النظام **محلي بالكامل** (يشتغل على نفس الكمبيوتر ويفتح في المتصفح). الداتا على الجهاز،
> ومافيش أي اعتماد على الإنترنت بعد التثبيت. بعد التجهيز، صاحب المحل **بيفتح النظام بدوبل
> كليك واحد** على اختصار اسمه **«نظام المحل»** — من غير أوامر ولا نوافذ سوداء.

---

## 🧭 الفكرة باختصار

- في **وضع المحل** الخادم (Backend) بيقدّم الواجهة (Frontend) من نفس المكان.
- العنوان الوحيد اللي بيتفتح هو:
  ```
  http://localhost:8080
  ```
- مفيش حاجة اسمها «شغّل الواجهة لوحدها» — كله بيشتغل من ملف واحد.

---

## 👨‍🔧 أول مرة فقط (المطوّر/المسؤول — مرة واحدة)

التثبيت بيتعمل مرة واحدة على كمبيوتر المحل. محتاج إنترنت في الخطوة دي بس.

### 1) ثبّت البرامج المطلوبة
- **Node.js 24** — من <https://nodejs.org> (لازم إصدار **24** أو أحدث؛ النظام بيستخدم
  `node:sqlite` اللي مش موجود في الإصدارات الأقدم). للتأكد: `node -v` لازم يطلع `v24.x`.
- **Git** — من <https://git-scm.com/download/win>.
- **pnpm** — هيتثبّت تلقائيًا من `Setup POS.bat`، أو يدويًا: `npm install -g pnpm`.

### 2) نزّل الكود
افتح **Command Prompt** واكتب (المكان المقترح `C:\POS`):
```
cd C:\
git clone https://github.com/Usama1917/Local-First-Pos.git POS
cd POS
```

### 3) شغّل الإعداد لأول مرة
دوبل كليك على:
```
Setup POS.bat
```
ده بيفحص Node/Git/pnpm، يثبّت الحزم (`pnpm install`)، ويبني النظام (`build:shop`).
لما يقول **«تم الإعداد بنجاح»** يبقى تمام.

### 4) اعمل اختصار سطح المكتب
دوبل كليك على:
```
Create Desktop Shortcut.vbs
```
هيظهر على سطح المكتب اختصار اسمه **«نظام المحل»**.

---

## 🛒 الاستخدام اليومي (صاحب المحل — بدون أي تقنيات)

- **دوبل كليك على اختصار «نظام المحل»** على سطح المكتب.
- النظام بيشتغل لوحده، والمتصفح بيفتح على `http://localhost:8080`.
- يظهر **تسجيل دخول**: المستخدم `admin` وكلمة المرور `admin123` (غيّرها بعدين).
- خلاص — النظام جاهز للبيع والجرد والفواتير.

> لو الاختصار اتقفل بالغلط، نفس الدوبل كليك بيفتحه تاني. ولو النظام شغّال أصلًا،
> بيفتح المتصفح على طول من غير ما يفتح خادم تاني.

بدائل لو حبيت:
- **`Start POS.bat`** — نفس التشغيل بس بيظهر نافذة فيها رسائل (مفيدة لو في مشكلة).
- **`Start POS Hidden.vbs`** — تشغيل صامت (ده اللي الاختصار بيستخدمه).

## 🔌 التأكد إن كل حاجة شغّالة

- الواجهة: <http://localhost:8080>
- صحة الخادم: <http://localhost:8080/api/healthz> — لازم يطلع `{"status":"ok"}`.

## 💾 مكان حفظ البيانات

- افتراضيًا قاعدة البيانات في:
  ```
  C:\POS\data\store.db
  ```
- **ممنوع تمسح `store.db`** — دي فيها كل بيانات المحل.
- تقدر تغيّر مكان الحفظ **من داخل البرنامج**: الإعدادات → النسخ الاحتياطي →
  «مكان حفظ قاعدة البيانات» → اكتب مسار (مثلًا `D:\POS-Data`) → احفظ → **أعد التشغيل**.
  (لو عندك بيانات قديمة، انقل ملف `store.db` للمكان الجديد قبل التشغيل.)
- ملفات الداتا وملف السجل **مش بترفع على GitHub** (متجاهلة)، فالتحديثات ما بتلمسهاش.

---

## 🛟 النسخ الاحتياطي

من **الإعدادات → النسخ الاحتياطي → «إنشاء نسخة احتياطية»**:
- بيعمل **ملف مضغوط `.zip`** فيه قاعدة البيانات، والمتصفح **بيسألك تحفظه فين**
  (نزّله على فلاشة مثلًا).
- النسخ القديمة بتظهر في القائمة وقدّام كل واحدة زرار **تنزيل**.

> اعمل نسخة احتياطية **يوميًا** على فلاشة أو هارد خارجي.

---

## 🔄 تحديث النظام (المطوّر/المسؤول)

1. (مُستحسن) قفل النظام بتشغيل **`Stop POS.bat`**.
2. دوبل كليك على **`Update POS.bat`**. ده بيعمل بالترتيب:
   - **نسخة احتياطية لقاعدة البيانات الأول** في `backups\store-backup-YYYY-MM-DD-HH-MM-SS.db`.
   - `git pull origin main`
   - `pnpm install`
   - `pnpm run build:shop`
3. بعد ما يخلص، شغّل النظام عادي من الاختصار.

> النسخة الاحتياطية **بتتعمل قبل** أي تحديث. ولو فشل التحديث، الرسالة بتقولك إن النسخة
> الاحتياطية اتعملت ومكانها في مجلد `backups`. التحديث **مش بيمسح ولا بيستبدل** قاعدة بياناتك.

> **التحديث بدون مشاكل:** قاعدة البيانات **بتترقّى لوحدها** أول تشغيل بعد التحديث (أي أعمدة/
> جداول جديدة بتتضاف تلقائيًا من غير خطوة يدوية وبدون فقد بيانات). فقط تأكد إن **Node.js 24**
> أو أحدث متثبّت، وسيب `pnpm install` يكمّل لوحده، وبعدها شغّل النظام عادي من الاختصار.

---

## ⏹️ إيقاف النظام

دوبل كليك على **`Stop POS.bat`** — بيوقف الخادم اللي على المنفذ 8080 بس.

## ❗ حل المشاكل السريع

| المشكلة | الحل |
|---|---|
| الصفحة مش بتفتح | استنى ثانية وجرّب `http://localhost:8080`. لو لسه، افتح `logs\pos-server.log`. |
| `node:sqlite ... No such built-in module` | إصدار Node قديم — ثبّت Node 24 (`node -v`). |
| النظام بيقول «شغّال بالفعل» | تمام، النظام فاتح؛ المتصفح هيفتح على طول. |
| المنفذ 8080 مشغول بحاجة تانية | اقفلها أو شغّل `Stop POS.bat`. |
| محتاج تتابع الأخطاء | كل رسائل الخادم بتتكتب في `logs\pos-server.log`. |

## 📁 ملفات التشغيل (مرجع سريع)

| الملف | لمين | بيعمل إيه |
|---|---|---|
| `Setup POS.bat` | المطوّر (مرة واحدة) | يفحص المتطلبات + `pnpm install` + بناء أول مرة. |
| `Create Desktop Shortcut.vbs` | المطوّر (مرة واحدة) | يعمل اختصار «نظام المحل» على سطح المكتب. |
| `Start POS.bat` | يومي | يشغّل الخادم على 8080 ويفتح المتصفح (بنافذة رسائل). |
| `Start POS Hidden.vbs` | يومي | نفس التشغيل لكن صامت (الاختصار بيستخدمه). |
| `Stop POS.bat` | عند الحاجة | يوقف الخادم. |
| `Update POS.bat` | المطوّر | نسخة احتياطية ثم `git pull` + `pnpm install` + بناء. |
