# استخدام النظام على الموبايل

- افتح نفس رابط HTTPS المستضاف وسجّل الدخول؛ لا تحتاج تطبيقًا منفصلًا.
- على الموبايل والتابلت، زر القائمة أعلى الشاشة يفتح كل الصفحات المسموح بها لحسابك.
- سلة الكاشير تظهر كبطاقات، وبنفس حسابات نسخة الكمبيوتر: كمية، خصم/إضافة، إجمالي، وحذف.
- الجداول الكبيرة تُسحب أفقيًا داخل الجدول نفسه، ولا تحتاج تصغير الصفحة. كل الأعمدة والأزرار باقية.
- النوافذ الطويلة تُمرّر رأسيًا للوصول لأزرار الحفظ، والتبويبات تلتف لصفوف عند ضيق الشاشة.
- حقول الخصم التي تقبل السالب تستخدم لوحة مفاتيح نصية لإتاحة علامة `-`؛ الكميات والمبالغ غير السالبة تستخدم لوحة الأرقام.
- تكبير الصفحة مسموح، وحجم خط الحقول على الهاتف يمنع التكبير التلقائي عند التركيز في متصفحات iOS الحديثة.

## تغيير بيانات الدخول

بحساب مدير: الإعدادات ← المستخدمون ← القلم بجانب الحساب.
يمكن تعديل اسم المستخدم وتعيين كلمة مرور جديدة، أو ترك خانة كلمة المرور فارغة للإبقاء عليها.
على الاستضافة يجب أن تكون كلمة المرور بين 12 و256 حرفًا. تغييرها يلغي جلسات الحساب القديمة.
متغيرات Railway تُستخدم فقط لإنشاء أول مدير عندما تكون قائمة المستخدمين فارغة؛ لا تستبدل الحسابات الموجودة عند إعادة النشر.

## فتح النظام بدون شاشة دخول

تسجيل الدخول اختياري. الوضع الافتراضي يفتح النظام مباشرةً لكل من يملك الرابط، ولا يحتاج اسم مستخدم أو كلمة مرور.
لإعادة تشغيل الحماية مستقبلًا أضف متغير Railway التالي ثم أعد النشر:

```text
POS_AUTH_ENABLED=1
```

عند تفعيلها، يعود استخدام حسابات النظام وبيانات المدير الأولى (`POS_ADMIN_USERNAME` و`POS_ADMIN_PASSWORD`) عند إنشاء قاعدة فارغة فقط. لا تشارك رابط النظام أثناء بقاء هذا الوضع المفتوح.

## حدود مهمة

- الواجهة المتجاوبة ليست مزامنة أو وضعًا بلا إنترنت. نسخة Railway تحتاج اتصالًا بالإنترنت.
- لا يتضمن هذا التعديل قارئ باركود بالكاميرا؛ يمكن البحث أو كتابة الكود، واستخدام قارئ خارجي متوافق مع الجهاز.
- الطباعة تعتمد على دعم المتصفح والهاتف والطابعة. بعض مسارات الطباعة تفتح نافذة جديدة؛ اسمح بالنوافذ المنبثقة عند الحاجة.
- تصفّح مجلدات Windows من الهاتف غير متاح؛ مسارات الاستضافة تبقى على الـVolume، وتنزيل النسخ اليدوية يتم من المتصفح.
- الاختبارات تحاكي أحجام الأجهزة ومحركات المتصفح؛ تبقى تجربة لوحة مفاتيح الهاتف والطابعة الفعلية مطلوبة قبل اعتماد التشغيل اليومي.

## اختبار المطور

```sh
pnpm exec playwright install chromium webkit
pnpm run test:mobile
```

الاختبار يبني التطبيق ثم يشغّل سيرفرًا مستقلًا على المنفذ `18881` بقاعدة مؤقتة وبيانات مصطنعة.
لا يقرأ قاعدة المحل أو أسرار Railway. يُغلق السيرفر وتُحذف قاعدة الاختبار عند انتهاء التشغيل الطبيعي.
لا تشغّل مجموعتين من هذه الاختبارات بالتوازي على نفس المنفذ.
اللقطات وتقارير الفشل في `test-results/` مستبعدة من Git.
لتجربة Chromium باستخدام Chrome المثبّت على الجهاز، يمكن استخدام `MOBILE_CHROMIUM_CHANNEL=chrome` مع مشاريع Chromium فقط.
